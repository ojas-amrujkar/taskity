1. Introduction

In fast-paced modern academic and engineering environments, task management tools often fail to sustain long-term engagement. Traditional to-do list applications act as passive repositories where tasks linger indefinitely without urgency, accountability, or positive psychological reinforcement.

Taskity is an engineering-grade, full-stack productivity web application designed to bridge the gap between static task tracking and high-velocity execution. Built using Java (Spring Boot 2.7) for its robust backend service layer and React 18 for a reactive user interface, Taskity implements a Time Attack Sprint Engine, an Urgency Countdown Protocol, an EXP Leveling & Overdue Deduction Model, and a LeetCode-Style 28-Week Consistency Heatmap.

1.1 Motivation

The motivation stems from addressing two common psychological and engineering bottlenecks:

  • Parkinson’s Law: Work expands to fill the time allotted. Without visible, ticking countdowns, routine coding tasks take disproportionately long.
  • Lack of Real Accountability: Conventional apps never penalize missed deadlines. Taskity introduces realistic stakes through Focus EXP rewards and overdue EXP deductions.
  • Habit Visualization: Visual contribution grids (like LeetCode and GitHub) drastically improve user retention and habit formation through positive reinforcement.

1.2 Relevance to Learning Java Programming Concepts

Developing Taskity provided hands-on mastery of core and enterprise Java concepts:

  • Object-Oriented Programming (OOP): Strict encapsulation of entities, domain modeling with enums, and abstraction via interface-driven service contracts.
  • Spring Boot & Spring Data JPA: Automated schema creation, CRUD repository abstraction, transaction boundaries with @Transactional, and loose coupling via dependency injection.
  • Date-Time Handling (java.time.LocalDateTime): ISO-8601 parsing, Jackson serialization annotations (@JsonFormat), and timestamp manipulation.
  • Java 8 Stream API: High-efficiency data pipelines, custom priority comparators, and in-memory sorting.

2. Objectives

  • To apply core Java programming fundamentals: Implement an enterprise-grade multi-tier web application adhering to standard industry practices.
  • To design and implement Object-Oriented concepts: Utilize encapsulation, interface contracts (TaskService), and centralized error handling (@ControllerAdvice).
  • To build a functional sprint time attack engine: Provide pre-configured time sprints (15m, 30m, 1h, Today EOD, and Custom) linked to Java timestamps.
  • To enforce gamified accountability: Award Focus EXP for on-time finishes, and enforce EXP deductions (-30 to -50 XP) and streak breaks if deadlines are missed or abandoned.
  • To develop a 28-week consistency heatmap: Track daily completed tasks with a 5-tier intensity color scale inspired by LeetCode.

5. Implementation & Results

5.1 Step-by-Step Working

  1. Task Creation with Sprint Timers: User selects presets (e.g. 15m Sprint). Frontend sends ISO timestamp to Spring Boot.
  2. Live Countdown Urgency: Task card updates every 1 second: Calm (>30m) → Warning (10-30m) → Critical Sprint (<10m) → Overdue (<0m).
  3. Reward & Penalty Loop:
    • On-time completion: +50 to +75 XP, confetti burst, streak increments (+1).
    • Overdue completion: -30 to -50 XP deducted, streak broken to 0.
    • Abandoning/deleting overdue task: -25 XP penalty.
  4. LeetCode-Style Activity Heatmap: Daily completions dynamically illuminate the 28-week matrix with 5 intensity shades.
